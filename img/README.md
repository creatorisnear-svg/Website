# Photos

The site loads photos from this folder by file name. To swap a photo, overwrite the file and keep the same name. No code changes needed.

| File name | Where it appears |
| --- | --- |
| `gallery-1.jpg` | Big background photo at the top of the home page (two-story home in teal), and in the gallery |
| `hero.jpg` | About section and the big gallery tile (single-story home, warm white) |
| `gallery-2.jpg` | Gallery: covered patio, warm white |
| `gallery-3.jpg` | "Made for Arizona homes" section and the gallery: eave corner showing the track |
| `gallery-4.jpg` | Gallery: track close-up |

Tips:

- Use `.jpg` files around 1600 px wide and under about 500 KB. `gallery-1.jpg` is full size; the others are small (about 640 px wide), so they look a little soft on large screens. Replacing them with the full-size originals from your phone will sharpen them up.
- The top photo fills the whole screen, so use a wide nighttime shot with the house centered.
- Gallery tiles are cropped square, so keep the house centered.
