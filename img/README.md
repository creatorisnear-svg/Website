# Photos

Drop your photos in this folder with these exact file names and they show up on the site automatically. No code changes needed.

| File name | Where it appears | Suggested size |
| --- | --- | --- |
| `hero.jpg` | Big photo at the top of the home page (nighttime shot of a lit house) | 1600 x 1200 px |
| `gallery-1.jpg` | Gallery, photo 1 | 1200 x 900 px |
| `gallery-2.jpg` | Gallery, photo 2 | 1200 x 900 px |
| `gallery-3.jpg` | Gallery, photo 3 | 1200 x 900 px |
| `gallery-4.jpg` | Gallery, photo 4 | 1200 x 900 px |
| `gallery-5.jpg` | Gallery, photo 5 | 1200 x 900 px |
| `gallery-6.jpg` | Gallery, photo 6 | 1200 x 900 px |

Tips:

- Use `.jpg` files. Keep each one under about 500 KB so the page loads fast on phones (most phone photos can be resized with the built-in Photos app or a free tool like squoosh.app).
- Photos are cropped to a 4:3 shape on the site, so keep the house centered.
- Until a photo is added, a neutral "Photo coming soon" tile is shown in its place.
